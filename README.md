# WebP Resim Optimizer 🖼️

**WebP Resim Optimizer**, WordPress sitenizin hızını ve performansını artırmak için geliştirilmiş akıllı bir görsel optimizasyon eklentisidir. Belirlenen hedef dosya boyutuna (KB) ulaşana kadar görsel kalitesini ve çözünürlüğünü kademeli olarak optimize eder. Both **GD** and **ImageMagick** libraries are fully supported.

## ✨ Özellikler
* **Akıllı Hedef Boyut Algoritması:** Sizin belirlediğiniz maksimum KB sınırına ulaşana kadar otomatik sıkıştırma.
* **Tam WebP Dönüşümü:** JPEG, PNG, GIF ve BMP formatlarını otomatik olarak yeni nesil WebP formatına çevirir.
* **Thumbnail Desteği:** WordPress alt boyutlarını da optimize eder.
